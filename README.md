## 🌟 Introdução
Este projeto consiste na criação de uma **Calculadora de Médias** desenvolvida com **HTML, CSS e JavaScript**.  
O objetivo é permitir que o usuário insira várias notas, calcule a média e determine se o estudante foi **aprovado ou reprovado** (média mínima: 6).  
A interface é simples, clara e interativa, facilitando a adição de notas e a visualização do resultado final.

---

## 🏗️ Estrutura do Projeto
O projeto possui três arquivos principais:

- **index.html** – Estrutura e layout da calculadora.  
- **styles.css** – Estilização e design da interface.  
- **solucao-algoritmo.js** – Lógica de manipulação das notas e cálculo da média.

---

## 📝 HTML (`index.html`)
Define a estrutura básica da calculadora:  

- Título: "Calculadora de Médias".  
- Campo de entrada para inserir notas.  
- Botões: "Adicionar Nota" e "Calcular Média".  
- Lista dinâmica das notas inseridas.  
- Parágrafo para exibir o resultado da média e indicar aprovação ou reprovação.

---

## 🎨 CSS (`styles.css`)
Estiliza a interface da calculadora com foco em **visual claro e amigável**:  

- Fundo da página: laranja claro (#F1A629) com texto em branco.  
- Calculadora: fundo azul (#1181cc) com sombras para destaque.  
- Botões: fundo verde (#00ff73) com texto preto.  
- Mensagem de resultado:  
  - **Aprovado:** fundo verde, texto preto.  
  - **Reprovado:** fundo vermelho, texto branco.

---

## ⚡ JavaScript (`solucao-algoritmo.js`)
Adiciona **interatividade** à página:  

- **Adicionar Nota:** insere a nota digitada em um array e exibe na lista.  
- **Calcular Média:** soma todas as notas, calcula a média e exibe o resultado.  
- **Feedback Visual:** dependendo da média, exibe mensagem de aprovação ou reprovação com estilo correspondente.

---

## 🎯 Conclusão
O projeto demonstra a combinação de **HTML, CSS e JavaScript** para criar uma ferramenta prática e interativa:  

- Interface intuitiva e responsiva.  
- Inserção de notas fácil e dinâmica.  
- Feedback visual claro sobre aprovação ou reprovação.  

Possíveis melhorias futuras:  
- Remoção de notas.  
- Inserção de pesos para notas.  
- Integração com plataformas educacionais ou armazenamento local.
